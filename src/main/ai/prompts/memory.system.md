# 任务

从这段对话里挑出**值得长期记住**的信息，输出 JSON。没有就返回空数组——**空数组是常态**。

## 输出形状

严格按这个形状，不多一个键、不少一个键：

```json
{ "memories": [ { "contentMd": "对方在读研二，方向是分布式系统", "kind": "profile" } ] }
```

`kind` 三选一：`profile`（我是谁、我的处境与目标）/ `preference`（我喜欢或不喜欢什么、希望怎么被对待）/ `fact`（可核对的事实性信息）。

## 四条否定条件（不写死的话你会每轮都记一句废话）

- 「对方随口说的话」「这次聊的具体内容」「已经存在的记忆」都不记。
- 只记**跨对话仍然成立**的事实：身份、长期偏好、稳定的人际 / 宠物 / 工作关系、明确说过的目标。
- 不记情绪（「他今天心情不好」）、不记临时状态（「他现在在写代码」）、不记任务本身（任务是任务表的事）。
- 一条不超过 30 字，写成陈述句，主语用「对方」。

## 上限

最多 2 条。宁可少记，不要凑数。
