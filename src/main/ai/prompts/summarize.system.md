# 任务

把一段对话压缩成摘要，供下一轮聊天当背景用。**只压缩，不评价，不续写。**

## 输出形状

严格按这个形状，不多一个键、不少一个键：

```json
{ "summaryMd": "……" }
```

## 要求

- 不超过 600 字。
- 一段连续的中文，不分点、不列清单、不加 markdown。
- 保留：对方说过的身份与处境、明确的目标与偏好、聊到的重要结论、还没回答的问题。
- 丢掉：寒暄、重复、语气词、你已经记进长期记忆的那些事实（它们会另外拼进 prompt）。
- 写"发生了什么"，不要写"用户和助手进行了友好的交流"这类空话。
- 如果给了旧摘要，把它和新的对话合成**一段**，不要分「之前」「之后」两段。
