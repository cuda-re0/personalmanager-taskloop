# taskloop · 架构与接口总册

桌面端任务应用：**AI 会话 → 任务 → 积分**。主窗左侧会话、右侧当前任务/日历/积分/明细，另有一个常驻屏幕顶部的悬浮条。

## 技术基线（已确认）

| 项 | 选择 |
|---|---|
| 桌面框架 | Electron + React 18 + TypeScript(strict) |
| AI | 智谱 GLM（默认 `glm-5.3-flash`，多模态） |
| 存储 | 本地 SQLite（better-sqlite3），单机无账号 |
| 悬浮形态 | `dock-bar`（顶部贴边）与 `float-pod`（自由浮窗）双模式可切换 |

## 阅读顺序

1. 先读 00 的 §2（三条不变量）与 §1（需求溯源表）。这两节读错，后面全错。
2. 再读 02 的类型定义部分，那是所有模块的公共语言。
3. 领到某个 W 后，读 05 里那一段 + 它引用的文档章节，**不要通读全册就当自己懂了**。

## 派活模板

给其他 AI 派工时，按这个格式发，比只发一句话有效得多：

```
【模块】W4 · AI 接入
【必读】docs/03-AI-CONTRACT.md 全文；docs/02-CONTRACTS.md §3.4 §5；docs/05-BACKLOG.md W4 段
【可改目录】src/main/ai/**、src/main/services/aiService.ts
【必须实现】<粘贴 W4 交付清单 1-8>
【验收】<粘贴 W4 验收清单>
【禁止】<粘贴 05 末尾协作纪律>
【交付时附】自检结果：哪几项通过、哪几项没过及原因
```
