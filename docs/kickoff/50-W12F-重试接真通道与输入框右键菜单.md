## 3. Part B：输入框右键菜单

### 3.1 新文件 `src/main/contextMenu.ts`

导出三个东西（纯函数与副作用分开，纯函数必须可单测）：

| 导出 | 签名 | 语义 |
|---|---|---|
| `EDIT_MENU_LABELS` | `readonly ['剪切','复制','粘贴','全选']` | 四项文字的唯一来源，**别处不许硬写这四个词** |
| `buildEditMenuTemplate` | `(flags: { canCut: boolean; canCopy: boolean; canPaste: boolean; canSelectAll: boolean }) => { label: string; enabled: boolean; separatorBefore?: boolean }[]` | 纯函数：返回四项，第 4 项带 `separatorBefore: true`。`enabled` 直接取对应 flag |
| `installContextMenu` | `(win: BrowserWindow) => void` | 挂 `win.webContents.on('context-menu', ...)` |

`buildEditMenuTemplate` 的规则：

1. **四项永远都在**，顺序固定 `剪切 / 复制 / 粘贴 / 全选`，`label` 取自 `EDIT_MENU_LABELS` 同一索引。
2. `enabled` 与传入 flag **一一对应**，不做任何合并推导。
3. **四个 flag 全 false 也要返回四项**（全禁用），不许返回空数组。
4. 只有第 4 项（全选）带 `separatorBefore: true`，其余项**不带这个字段**（不是 `false`，是不出现）。

`installContextMenu` 的实现要求（伪代码，代码自己写）：

```
模块级：let lastMenu: Menu | null = null

installContextMenu(win):
  win.webContents.on('context-menu', (_event, params) => {
    1  若 !params.isEditable → 直接 return          // 用户裁决：只管输入框，气泡里右键什么都不弹
    2  items = buildEditMenuTemplate(params.editFlags)
    3  template = []
       对每个 item：
         若 item.separatorBefore === true → template.push({ type: 'separator' })
         template.push({ label: item.label, enabled: item.enabled, click: 对应动作 })
       四个动作分别调 win.webContents 的 cut() / copy() / paste() / selectAll()，
       按 label 或按索引映射，别写四段重复代码之外的判断
    4  lastMenu = Menu.buildFromTemplate(template)
    5  lastMenu.popup({ window: win })
  })
```

**必须保留模块级引用** `let lastMenu: Menu | null = null`，每次 build 后赋给它。理由：`Menu.buildFromTemplate(...).popup()` 写成一行链式调用时，菜单对象可能在弹出期间被 GC，表现为"偶尔点了没反应"——这是 Electron 的经典坑，不能省。

其余约束：

- `params.editFlags` 的字段名是 `canCut` / `canCopy` / `canPaste` / `canSelectAll`，直接映射，别自己造名字。
- **不读剪贴板内容、不做自定义菜单项**（不加"粘贴为纯文本"之类）。
- 不打印日志。

## 8. 验收（4 条，别做分子料理）

1. **右键菜单**：输入框里打几个字 → 右键 → 出现 `剪切 / 复制 / 粘贴 / 全选` 四项 → 点「全选」再右键点「复制」→ 粘到记事本有内容。

3. **不越界**：在消息气泡的文字上右键 → **什么都不弹**。
4. **真重试**：把设置里的模型名改成一个不存在的（或断网）发一条 → 出「这次没读懂模型的回复」的红色卡 → 点 `重试` → **真的重新开始思考**（转圈、几秒后出新回复或新报错），不是毫无反应。验完把模型名改回来。
