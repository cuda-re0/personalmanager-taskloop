## §2 `hud.css`

### §2.1 新增右侧容器

在 `.hud-bar-ratio` 规则之后、`.hud-bar-temps` 之前插入：

```css
/* v0.64：长条右侧一格。平时温度、悬停星期，两种内容右边缘对齐；
   固定 min-width 是为了切换时左边不跟着跳（温度比星期宽） */
.hud-bar-side {
  display: inline-flex;
  flex: 0 0 auto;
  justify-content: flex-end;
  align-items: center;
  min-width: 40px;
}
```

### §2.2 温度：去掉 `flex` 那行、保持默认显示

`.hud-bar-temps` 保留 `display: inline-flex` / `align-items: baseline` / `gap: 3px`，**删掉 `flex: 0 0 auto`**（现在是 `.hud-bar-side` 的子元素，不再参与外层 flex）。

### §2.3 星期：默认隐藏 + 悬停显示

替换掉现在 `.hud-bar-temps` 上面那句旧注释（「v0.62：温度顶掉原来的「周X」…」），改成：

```css
/* v0.64：星期回来了，但只在悬停时露脸。12px / text-sub 沿用 v0.31 的旧值 */
.hud-bar-week {
  display: none;
  font-size: 12px;
  font-variant-numeric: tabular-nums;
  white-space: nowrap;
  color: var(--text-sub);
}

.hud-ball:hover .hud-bar-temps {
  display: none;
}

.hud-ball:hover .hud-bar-week {
  display: inline;
}
```

**三条规则缺一不可**：默认隐藏星期、悬停隐藏温度、悬停显示星期。少任何一条都会出现"两段叠在一起"或"悬停后空白"。

### §2.4 宽度核算（写给你对照，不是要你实现）

`20 padding + 20 环 + 6 gap + 20(3/5) + 6 gap + 40 side = 112px < 132px`。`min-width: 40px` 覆盖两个温度（约 37px）与「周三」（约 24px），两者都靠容器右侧。

## §8 已知影响

- **悬停切换靠 CSS，不额外发请求**。温度轮询仍每 2 秒一次，悬停期间照跑（切回去立刻有值）。
- **拖动过程中指针一直在长条上，会显示星期**。松手移开后变回温度，不影响拖动本身。
- **`min-width: 40px` 是硬编码宽度**。将来温度变成三位数（如 `100°`）或星期变长（如「星期一」）会溢出，那时调这一个数字即可。
