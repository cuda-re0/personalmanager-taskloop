## 3. Part A：重试接真通道（1 个文件）

`src/renderer/main/features/chat/useChatData.ts`，把 `retry` 换成：

```
const retry = useCallback((messageId: string) => {
  void window.api.msg.retry({ messageId })
    .then(res => { if (!res.ok) console.error('[chat] msg.retry 失败', res.error) })
    .catch(e => console.error('[chat] msg.retry 调用失败', e))
}, [])
```

三条约束：

1. **不要 `setSending(true)`。** 重试的转圈由主进程的 `ai.status`（`thinking` → `idle`）事件驱动，`sending` 只管输入框提交，两者混用会让输入框在重试期间错误地禁用。
2. **不要本地改消息状态**（原来那句 `setMessages(... status: 'sent')` 整个删掉）。状态由主进程 `message.patch` 事件回归，本地预改会和服务端的 `failed` 打架。
3. 失败只 `console.error`，**不弹红字、不加 toast**——与 `send` 的失败处理保持同一口径。

### 5.2 `messageRepo` 加两个删除方法

### 5.3 `aiService.removeTurn`（新导出函数）

放在 `retry()` **之后**。入参 `{ messageId: string }`，返回 `{ removedIds: string[]; removedTaskIds: string[] }`。

**范围定义（这是本单最容易做错的地方，逐字照做）**：

1. 用 `messageService.listMessages({ limit: 60 })` 拿到升序列表（与 `locateTurn` 同源，**不要**另写一套查询）。
2. 找到 `messageId` 那条。找不到 → `NOT_FOUND`「消息不存在」。
3. 校验它 `role === 'user'` 且 `kind === 'text'`。否则 → `INVALID_INPUT`「请求参数格式不正确」，`detail` 写清实际 role/kind。
4. **删除范围 = 这条消息起，到列表中下一条 `role === 'user'` 之前（不含下一条）**。用下标切片，不要按时间戳。
5. 范围内每一条 `kind === 'task_draft'` 的消息，遍历 `meta.drafts`，凡是带 `promotedTaskId` 字符串的，收集进 `taskIds`（去重）。
6. 整个操作在**一个 `tx(...)` 里**（`tx` 已在 aiService 里可用；它是 savepoint，嵌套安全）：
   - 对每个 `taskIds` 调 `taskService.removeTask(id)`（**软删**）。任务已被删过（`NOT_FOUND`）时**吞掉这个错误继续**，因为"撤回一条建了两个任务的草稿卡、其中一个已被用户删掉"是正常情况。
   - `messageRepo.removeMany(removedIds)`。
7. **事务外**广播（顺序固定）：
   - 每个删掉的任务 `broadcast({ type: 'task.removed', taskId })`
   - **不广播消息删除事件**（§2.3 最后一条已经说明：这一单不开 `message.removed`，渲染层用返回值自己过滤）
8. 返回 `{ removedIds, removedTaskIds: taskIds }`。

**不许做的事**：

- 不许删 `attachments` 的磁盘文件（`rel_path` 指向的文件留在 `userData/attachments/` 里）。W11 附件清理还没做，这一单不背这个账，写进已知边界。
- 不许动 `chat_state`（会话摘要）。摘要里可能提到已撤内容，这是可接受的陈旧数据。
- 不许用 `taskRepo.hardDelete`。软删就好：流水、打卡记录全部保留，任务只是从 ① 消失。
- 不许在删除前检查"这条消息是不是正在跑的那一轮"。跑动中的那条**在渲染层就不显示按钮**（见 5.6），主进程不做二次判断。

## 10. 验收（6 条，别做分子料理）

1. 在输入框里打几个字 → 右键 → 出现 `剪切 / 复制 / 粘贴 / 全选` 四项；现在能点「全选」，再右键「复制」；粘贴到别处有内容。
