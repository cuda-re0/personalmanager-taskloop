## 一、要解决什么

提醒弹过之后，程序不知道用户有没有看见。dsh（QQ 侧）想知道「哪条提醒用户没理」，现在完全没有数据源。

本单补上这条链：**每次真的投递（弹横幅或唤主窗）时记一条 alert → 用户确认就标 acked → 超时未确认就标 escalated → dsh 通过 MCP 轮询到未确认的，自己去提醒用户。**

三条已定口径：

- **只记 `reminder`，不记 pulse。** 高频周期提醒（喝水、起身）是打断性的，不需要外部追踪，也不该污染 dsh 的提醒队列。
- **`fresh === false` 不记。** 那种情况是提醒过期太久，连横幅都不弹，记一条只会让 dsh 去催一件用户从没看见的事。
- **记录失败不许影响投递。** 记不进去也要照常弹窗/唤主窗，不能因为写库失败让用户错过提醒。
