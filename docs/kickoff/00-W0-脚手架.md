## 交付清单

### 1. electron-vite 三入口

main / preload / renderer 两个入口（`main` 与 `hud`）。HUD 必须有独立的 HTML 入口，不能和主窗共用一个。

### 2. TS strict + 路径别名

`strict: true`，`@shared` 指向 `src/shared`。**两个渲染进程都要能 import**，别只配一个。

### 3. ESLint + Prettier

`npm run lint` 零错误、零警告。

### 4. better-sqlite3 装好并能跑

`electron-rebuild -f -w better-sqlite3` 必须做，`postinstall` 里也要写。在 main 里能 `new Database(':memory:')` 并执行一条建表语句不报错。

### 5. 两个窗口

- 主窗 1440×920，正常窗口，可缩放
- HUD 300×32，`transparent: true`、`alwaysOnTop: true`、`frame: false`、`skipTaskbar: true`、`resizable: false`
  - **300×32 只是骨架占位尺寸**，用来验证透明+置顶+不占任务栏这条链路通不通。
  - 最终形态由 W9 实现：`dock-bar` 是全宽条（`x=8, y=0, w=screen.width-16, h=32`），见 `04-UI-SPEC.md` §5.2。W9 会重写 `windowManager` 的尺寸计算，你现在不要按 04 去算全宽。

HUD 的 `backgroundColor` 用 `'#00000000'`，不要用默认值。

### 6. `src/shared/` 照抄清单（**一个字都不许改**）

按 `docs/02-CONTRACTS.md` 建：

```
src/shared/types/domain.ts      # Task / TaskPatch / Occurrence / Message / PointEntry / Reminder / DayStat / TaskDraft / ReviewVerdict / Evidence / DayTaskItem
src/shared/types/ipc.ts         # Bootstrap / ApiSurface 各方法的入参出参
src/shared/types/events.ts      # DomainEvent 联合类型
src/shared/channels.ts          # IPC 通道常量名
src/shared/points/rubric.ts     # DIFFICULTY_BASE / effortFactor / computePlannedPoints / computeAwardedPoints / RUBRIC_VERSION
```

`RUBRIC_VERSION` 导出一个字符串常量即可，值是 `'v0.6-b'`（B 档额度 + 小数积分）。

**禁止**：不许"优化"类型命名、不许拆文件、不许加 `Partial<>` 包装、不许把 `null` 改成 `undefined`。这六个文件是 6 个并行 AI 的唯一公共语言，你改一处，六个人全对不上。

### 7. 预留接线点（这一条最重要，原文档没写，是并行调度的必需品）

`src/main/index.ts` 里**写下这些调用行**，让后面的人只填自己的文件、不碰这个文件：

```ts
import { initDb } from './db'
import { registerIpcHandlers } from './ipc'

app.whenReady().then(() => {
  initDb()                                  // W1 填实现
  createMainWindow()
  createHudWindow()
  registerIpcHandlers()                     // W2 填实现
})
```

配套：

- `src/main/db/index.ts` 导出一个 `export function initDb(): void { /* TODO W1 */ }`
- `src/main/ipc/index.ts` 导出一个 `export function registerIpcHandlers(): void { /* TODO W2 */ }`

这样 W1 和 W2 各自改自己的文件，`src/main/index.ts` 谁都不用改，**避免两人同时改同一文件造成冲突**。
