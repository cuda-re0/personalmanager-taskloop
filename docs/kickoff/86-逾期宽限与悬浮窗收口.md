## 一、逾期自动宽限 24 小时（需求 1）

**现状**：`reviewFlow.decideReview` 的 `isOverdue` 是 `due < now`，一过截止点，审核驳回（`partial` / `fail`）就直接判 `missed`，而 `missed` 只能归档、不可复活。

**规格**

- 文件：`src/renderer/main/features/tasks/reviewFlow.ts`
- 新增导出常量 `OVERDUE_GRACE_MS = 24 * 60 * 60 * 1000`
- `isOverdue` 的判定改成：`due.getTime() + OVERDUE_GRACE_MS` **严格小于** `now` 才算逾期
  - 边界与现有的「`due === now` 不算逾期」同口径：`now === due + 24h` **不算**逾期
- **逐条不许动**：
  - `event` 的 `fail` 仍然**无条件** `missed`（活动看结果不看时间）
  - `pass → complete`、`need_evidence → stay` 两条分支一个字不动
  - `fmtRemaining`（`src/shared/format.ts`）里「逾期」的显示口径**不改**——过了截止时刻右栏照旧显示「逾期」，宽限只影响「驳回是否判死」
  - `src/main/db/stateMachine.ts` 的 `missed: ['archived']` **不改**，本单不给 `missed` 加复活出口
- 注释要写清三件事：①宽限期是用户 2026-11-06 的裁决；②宽限期内驳回回 `doing`，可以继续补交；③超过 24 小时之后的下一次驳回才判 `missed`

**测试（不改必红）**

- `tests/renderer/reviewFlow.test.ts` 里 `OVERDUE = { dueAt: '2026-10-29T12:00:00.000Z' }`，与 `NOW`（`2026-10-30T12:00:00.000Z`）正好差 24 小时 → 加宽限后它变成「未逾期」，`partial → missed` / `fail → missed` 两条断言会红。把它改成 `2026-10-28T12:00:00.000Z`（差 48 小时）。
- 新增两条边界用例：①`dueAt` = `now − 24h` 整 → 期望 `revive`；②`dueAt` = `now − 24h − 1ms` → 期望 `missed`。

## 二、悬浮窗只留一周 + 行尾显示截止日期（需求 2）

**口径（用户裁决）**：截止日落在「**今天 ~ 今天 +7 天**」之间（含两端）才显示。

**规格**

- `src/renderer/hud/hudModel.ts`
  - `HudRow` 增加字段 `dueLabel: string`（每日打卡行恒为 `''`）
  - 新增导出 `hudDueLabel(dueAt: string | null): string`：走 `dueLocalDay`（`@shared/due`，它已把 `day` 归当天、`month` 归月末），返回 `MM-DD`；`null` / 非法 → `''`
  - 新增导出 `withinHudWindow(tasks: Task[], today: string): Task[]`，规则三条：
    1. `status` 是 `done` 或 `missed` → **保留**（今天刚结束的必须看得见，不受窗口限制）
    2. `dueLocalDay(dueAt)` 为 `null` → **保留**（判不出日期就不凭空丢）
    3. 其余：`today <= dueDay <= today+7` 才留；日期比较用 `YYYY-MM-DD` **字符串字典序**，不要转成 Date 比毫秒
  - `today+7` 用本地日历加（`new Date(y, m, d + 7)` 再 `toLocalDay`），**不许**用 `toISOString()` 切日期
- `src/renderer/hud/useHudData.ts`
  - `rows` 的 `useMemo` 里套一层：`buildRows(snapshot.occurrences, withinHudWindow(snapshot.tasks, today))`
  - `today` 在组件体里算一次（`toLocalDay(new Date())`），加进 `useMemo` 依赖数组
  - **不要**改 `handleEvent` 的任何分支；**不要**改 `mergeTodayFinished`——过滤只在装配层做一次
  - `done` / `total` 由 `rows` 派生，自然跟着变，不要另算一套
- `src/renderer/hud/HudPanel.tsx`
  - 行内标题之后渲染 `<span className="hud-row-date">{row.dueLabel}</span>`；`dueLabel === ''` 时**不进 DOM**
- `src/renderer/hud/hud.css`
  - `.hud-row-title` 补 `flex: 1 1 auto; min-width: 0`（不补日期会被挤出可视区）
  - 新增 `.hud-row-date`：`flex: 0 0 auto`、`font-size: 11px`、`color: var(--text-faint)`、`font-variant-numeric: tabular-nums`

**测试**

- `tests/renderer/hudModel.test.ts` 第一条用例是 `expect(rows).toEqual([...])` 整对象比较，多出 `dueLabel` 会红 → 两条期望对象各补 `dueLabel`（该用例的 occurrence 行 `''`、限时任务没给 `dueAt` 所以也是 `''`）
- 新增 3 条：①`withinHudWindow` 丢掉 8 天后的任务；②保留 `status` 为 `done`/`missed` 的旧任务；③`dueAt` 为 `null` 保留
