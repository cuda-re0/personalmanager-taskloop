## §0 现象与根因（已定位，不要另行发挥）

**现象**：点证据缩略图后，大图只盖住聊天区的一部分，四周没有暗色遮罩，图片本身半透明、能透出下面的卡片文字，位置偏下并可能出到窗口外。

**根因，两条叠加：**

1. `src/renderer/main/features/chat/MessageList.tsx:55` 的 `.msg-row` 带内联 `transform: translateY(${top}px)`（虚拟滚动的定位方式）。**任何 `transform` 不为 `none` 的祖先都会成为 `position: fixed` 的包含块**。`.lightbox` 写在 `TaskReviewCard` / `SubmitCard` 内部，所以它的 `inset: 0` 只覆盖那一条消息行，不是整窗。
2. `chat.css` 的 `.lightbox` 上有 `opacity: 0.88`，它作用在**容器**上，会把里面的 `<img>` 一起变成 88% 不透明，于是图片发白、能透过它看到下面的文字。

不是构建问题、不是 CSS 丢包、不是图片路径问题。

## §1 改法（唯一允许的改法）

用 `createPortal` 把预览层挂到 `document.body`，让它脱离 `.msg-row` 的包含块。

### §1.1 `TaskReviewCard.tsx` 与 `SubmitCard.tsx`（两处完全一致）

- 新增 `import { createPortal } from 'react-dom'`。
- 把现在这段（两文件里各一份，内容相同）：

```tsx
{opened ? (
  <div className="lightbox" onClick={() => setOpened(null)} role="presentation">
    <img alt="" className="lightbox-img" src={opened} />
  </div>
) : null}
```

改成 `createPortal(...)` 包住同一个 `<div>`，第二个参数 `document.body`，外层条件渲染不变：

```tsx
{opened ? createPortal(
  <div className="lightbox" onClick={() => setOpened(null)} role="presentation">
    <img alt="" className="lightbox-img" src={opened} />
  </div>,
  document.body
) : null}
```

**硬规定：**

- `onClick` / `role="presentation"` / `alt=""` / `src={opened}` **一个字都不改**。
- 不加关闭按钮、不加提示文字、不加缩放、不加左右切换。
- **不要**把 `.msg-row` 的 `transform` 改成 `top`。那是虚拟滚动的定位基础，改它会动到滚动测量与 `tasksPanelWiring` 之外的多处行为。本单不碰 `MessageList.tsx`。
- 两处写法必须一样，不要一处 portal 一处留原样。

### §1.2 `src/renderer/shared/styles/chat.css`

`.lightbox`：

- **删掉** `opacity: 0.88`（这一行是本单的主要修复点之一）。
- `background: var(--text)` → `background: color-mix(in srgb, var(--text) 86%, transparent)`（保持「颜色只取 tokens 变量」的规矩，不写死色值；Electron 33 = Chromium 130，`color-mix` 可用）。
- `z-index: 30` → `300`（portal 到 body 后要与设置抽屉的 40/41 同层竞争）。
- 新增 `cursor: zoom-out`。
- 新增 `padding: 24px`（图片不贴边）。
- 其余属性（`position` / `inset` / `display` / `align-items` / `justify-content`）一个字不动。

`.lightbox-img`：

- `max-width: 80vw` → `92vw`；`max-height: 80vh` → `92vh`。
- 新增 `object-fit: contain` 与 `display: block`。
- `border-radius` 不动。

**禁止**：在 `.lightbox` 上加 `opacity`（哪怕是 0.99）、加 `filter`、加 `transform`——前两个会把 `<img>` 一起拖进透明度体系，第三个会再制造一层包含块，等于回到 bug 原点。
