## 交付

### 1. `dock-bar` 顶部贴边条

按 `04-UI-SPEC.md` §5.2 的两张 ASCII 图：

**收起态（h = 32）**：`● 3/5   今日 +42   ⋯   最近待办标题 →`

**展开态（h = 260）**：上面一行不变，下面展开任务列表（最多 6 条）+ 底部快速输入框。

细节：

- 圆角只在下方两角：`border-radius: 0 0 14px 14px`
- 状态点：`doing` 实心、`todo` 空心
- 列表项右侧显示时长或分值（按 04 的图，`30min` / `10:00` / `+20` 三种都支持）
- 超过 6 条显示 `⋯ 最多 6 条`

### 2. `float-pod` 自由浮窗

- 收起态 `56 × 56` 圆形：积分环（圆环进度 = 今日完成率）+ 右下角待办数角标
- 圆整体可拖：`-webkit-app-region: drag`（但内部如果有可点元素，要 `no-drag`，否则点不动）
- 展开态 `360 × 480` 面板：内容就是同一份 `HudPanel`（任务列表 + 输入框 + 今日积分）
- 展开时从圆的位置向屏幕内侧弹出

### 3. `HudPanel` 内容组件（两种模式共用）

- 任务列表（最多 6 条）+ 勾选完成
- 底部快速输入：`[+] 一句话加任务…` + 回车提交
- 今日积分显示

**输入区在收起态不渲染**（高度不够，硬塞会挤成一团）。

### 4. 透明背景

HUD 窗口是透明的（W0 已配 `backgroundColor: '#00000000'`）。所以：

- `body` 和根容器 `background: transparent`
- 视觉上的"条"和"圆"由内部 div 自己画背景 + `border-radius`，**不要给 `html/body` 设任何背景色**
- 注意不要出现黑色方块（这是透明窗最常见的坑，多半是给 `body` 设了默认白/黑底）
