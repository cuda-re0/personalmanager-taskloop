## 这一轮的范围（严格）

只做**纯展示组件**，数据全部由 props 传入：

```ts
interface CalendarProps {
  year: number
  month: number                          // 1-12
  dayIndex: Record<string, DayStat>      // key = 'YYYY-MM-DD'
  selectedDay: string | null
  onSelectDay: (day: string) => void
  onMonthChange: (year: number, month: number) => void
  dayDetail: DayTaskItem[] | null        // 选中日的条目，null = 未加载
}
```

**不要在组件里调 `window.api`。** 数据接入由后续轮次在容器层做。你现在调了，W1 的查询一旦改形状就要返工。

## 交付

### 1. 月视图

- 7 列（周一开始，不要周日起）
- 每格：日期数字 + 红点
- 高度固定 240px，不显示农历、不显示节假日
- 今日格加描边
- 上/下月切换按钮 + 当前年月标题

### 2. 红点规则（这块是重点）

- 该日有任务 → **实心红点**
- 该日任务全部完成 → **空心圈**（不是红点变淡，是空心）
- 该日无任务 → 不显示任何标记
- **一天最多一个点**。三个任务也是一个点，不叠加

`DayStat` 里区分这些用 `points` 和 `tasksDone` / `tasksTotal`（按 02 类型定义取字段，如果字段不够用，停下来报告，不要自己加）。

### 3. 点击展开

点有任务的日期 → 浮层展开当日列表（`04-UI-SPEC.md` §4② 的 ASCII 图）：

```
┌────────────────────────────────────┐
│ 10 月 27 日 周二               ×   │
├────────────────────────────────────┤
│ 18:00  交物理作业   限时  ·  23 分 │
│ 09:00  英语六级考试  活动  ·  50 分 │
└────────────────────────────────────┘
```

- 每行：`时间 · 标题 · 类型标签 · 分值`
- 已完成的行：标题删除线 + 整体降透明度
- 按时间升序
- **点无任务的日期不响应、不弹空面板**
- 点击浮层外部或 `×` 关闭
- 点某行 → 调 `props.onTaskClick?.(taskId)`（如果容器还没提供，先留可选回调）

### 4. 切月

调 `props.onMonthChange(year, month)`。组件自己不做任何数据请求。
