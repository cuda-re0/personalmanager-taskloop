## B 规格

### B1 编辑态：类型按钮改成「写库但不关闭」

现状：`onRepeatKind` 调 `commitRepeat(...)`，成功后 `setRepeatOpen(false)`，编辑态关闭。

给 `commitRepeat` 增加第二个参数（是否关闭），触发时机与关闭行为**写死**如下：

| 触发 | 是否写库 | 写成功后是否关闭编辑态 |
|---|---|---|
| 点四个类型按钮之一 | 是 | **否** |
| 焦点移出整个编辑区容器（`onBlur` 且 `relatedTarget` 不在容器内） | 是 | 是 |
| 输入框内按 Enter | 是 | 是 |
| 草稿非法（现有 `null` 分支或 `parseRepeatRule` 抛错分支） | 否 | 是（回只读、原值不变） |
| 写库失败（`res.ok === false`） | — | **否**，保持编辑态并 `console.error`（现有行为，不许改） |

要点：

- 类型按钮点击仍先 `setRepeatUnit(next)`，写库用**新 unit** + 当时其余草稿值；现有调用点已这么传，只加关闭标志，不要改传参内容
- 「不关闭」不许连带改写任何草稿 state
- 其余一律不动：`ruleOfDraft`、`openRepeat`、周几「取消最后一个已选项无效」的守卫、无保存按钮、`parseRepeatRule(serialized)` 的越界自检

### B2 只读态：从按钮外观改成纯文字

- **不许**把 button 换成 span/div——保留可聚焦、可键盘触发的语义，只换类名
