## 0. 一句话目标

右栏 ④ 现在只是「今日/本周/本月」三档的短列表，用户要一个**能看完整账的地方**。本轮新建一个**明细页**：按月翻，按日分组，每行是「时刻 + 标题 + ±N」，顶部给当月净额。柱子图（③）**保留不动**。

## 2. 页面结构（照这个做，不要加戏）

```
┌────────────────────────────────────────────────┐
│  ←     2026年10月   ‹  ›                 +12   │  页头 48px
├────────────────────────────────────────────────┤
│  10月28日                                  +3  │  分组头（sticky）
│    00:18   写季度复盘初稿                  +1  │
│    10:03   交实验报告                      +2  │
│  10月27日                                  -1  │
│    21:30   逾期扣分                        -1  │
└────────────────────────────────────────────────┘
```

### 2.1 页头

- 左：`←` 返回按钮（24×24，无边框，`aria-label="返回"`）。点它回到工作台视图。
- 中：月份 `2026年10月`，两侧 `‹` `›` 切月。
  - `›` 在**当前月**时 `disabled`（不能看未来月）。
  - `‹` 无下限，但**空月就留白**，不要造一个"最早"边界。
- 右：**当月净额**，用 `fmtPoints` 后加符号（`+12` / `-1` / `0`），正数主色、负数灰红，和 ④ 的行内 `±N` 同一套样式来源。

### 2.2 列表

- 按 `day` 分组，**组间按 day 降序**；组内按 `createdAt` 降序。
- 分组头：`10月28日` + 右侧该日净额。**不写「今天」「昨天」**（不引入相对时间语义，省得跨天边界出错）。
- 每行：`HH:mm` + `reasonText`（超长省略号）+ `±N`。行高 `32px`。
- 已冲销行（`reversedAt !== null`）整行 `opacity: .5`，和右栏 ④ 一致。
- 行可点：有 `taskId` 时 → 切回工作台视图并高亮该任务（复用现成的 `emitFocusTask`）。
- **本页不放 `[撤销]`**：撤销入口只有右栏 ④ 一处（04 §4④）。双入口迟早不一致。

### 2.3 空月份

整页只有页头，列表区**留白**。不写「暂无记录」「本月还没有流水」之类的字（04 §7 空状态留白原则）。

## 4. 数据（只用已接通的读通道，不要新增 IPC）

| 用途 | 通道 | 说明 |
|---|---|---|
| 当月流水 | `points.ledger({ from, to, limit: 500 })` | `from` = 当月 1 号、`to` = 当月最后一天（按实际天数算，不要写死 30） |
| 当月净额 | `points.monthStats({ year, month })` | 求和 `DayStat.points`。**不要用 ledger 求和**：`limit: 500` 被截断时净额会错 |

- 分组、日净额、月份格式化都放在**纯函数**里（`pointsModel.ts` 追加导出，或新建 `ledgerModel.ts`），组件里不许写日期算术。
- 复用现成的 `shiftDay` / `localDayOf` / `fmtPoints`，**不许再写一份 `toLocalDay`**（v0.20 已经收编为 `@shared/localDay`，全项目只留一份）。
- 请求失败：`console.error` 就地日志，页面保持空列表，**不弹 toast、不写红字**（本页是只读浏览，失败重进即可）。

## 7. 硬性口径（逐条自检，报告里给证据）

| # | 口径 | 判定方式 |
