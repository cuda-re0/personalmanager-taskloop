## 3. 改动 B —— `chat.css`

### 3.1 先把共用的尺寸声明拆开（关键，别漏）

现在 `.ci-plus, .ci-mode { ... }` 里含 `width: 28px; font-size: 16px;`。因为 `[模式]` 要变宽，
必须把这条选择器拆成两条独立规则：**`[+]` 保持原样（28×28、font-size 16px、圆角、边框、hover 全不变）**；
`[模式]` 自己一套。共用的只剩 `flex: 0 0 auto; height: 28px; border-radius; cursor` 这类不影响宽度的。

### 3.2 `[模式]` 的新规则

| 属性 | 值 | 说明 |
|---|---|---|
| `width` | `auto` | 不再固定 28px |
| `height` | `28px` | 与 `[+]` 等高，一行内不跳动 |
| `padding` | `0 8px` | 四字 12px ≈ 48px，加内边距 ≈ 64px |
| `font-size` | `12px` | 沿用，别放大 |
| `white-space` | `nowrap` | 不许折行 |
| `flex` | `0 0 auto` | 不被 textarea 挤扁 |
| `background` | `var(--accent-weak)` | 淡蓝底 = `#eaf1fe` |
| `border` | `1px solid #c9dcfb` | 淡蓝描边 |
| `color` | `var(--accent)` | 蓝字 = `#2f6feb` |
| `border-radius` | `var(--r-sm)` | 沿用 |
| `line-height` | `1` | 沿用 |
| `cursor` | `pointer` | 沿用 |
| `transition` | `background-color .12s` | 可选，短即可 |

hover（`[+]` 原本就有 hover，`[模式]` 原来没有，补一条保持手感一致）：

```
.ci-mode:hover { background: #dce9fd; }
```

### 3.3 两种模式**颜色一致**

`.ci-mode--task` 与 `.ci-mode--chat` 的**配色全部相同**——状态只由文字表达。
这两个类名**保留**（组件里的三元表达式不改），但不再承担颜色差异：可以直接删掉
`.ci-mode--task { background/border-color/color }` 与 `.ci-mode--chat { ... }` 里的颜色声明，
只留 `.ci-mode` 一套。**不要删类名、不要删 `className` 里的三元表达式**。
