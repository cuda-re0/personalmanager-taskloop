## 1. 任务 A：fewshot 第 3 例的 deadline 去掉编造的时刻

`src/main/ai/prompts/parse.fewshot.json`，「多任务：一条 event + 一条 deadline」这一例里，
`交实验报告` 那条的 `due_hint`：

```
"2026-10-30T18:00:00+08:00"   →   "2026-10-30"
```

**为什么非改不可**：用户原话是「这周五前要把实验报告交了」，没有钟点。留着 `18:00` 等于在
fewshot 里放了一条"只有日期却自己补了时刻"的示范——**示例对模型的影响比 system 正文更大**，
这一条会把 51 整单想纠正的行为又教回去。同例的 event 你已经改成 `2026-11-04` 了，这条是同一类。

改完该例的两条 `due_hint` 分别是 `2026-11-04`（event）与 `2026-10-30`（deadline），
`note` 里「示例 2 / 3 演示只有日期」的表述自动成立，**note 不用再改**。

> 第 1 例（「明天下午三点前」→ `2026-10-30T15:00:00+08:00`）**保持不动**：用户确实说了三点。
