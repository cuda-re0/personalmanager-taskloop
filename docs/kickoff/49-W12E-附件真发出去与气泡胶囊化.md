## 0. 一句话目标

1. **图片发不出去**：用户贴了一张截图、打了字、按发送——气泡里**什么都没有**。附件从头到尾没上传，`msg.send` 也没带 `attachmentIds`。把它接上。
2. **气泡照用户给的截图改**：附件在气泡里是**胶囊**（蓝底图标 + 文件名），**鼠标悬停胶囊**才浮出缩略图；气泡右下角**常驻**一行「时间 · 复制 · 撤回 · 编辑」。
3. **不打字只发图也算一条消息**（现在会被守卫拒掉，界面上表现为"点了没反应"）。

## 3. Part B：上传链路（图片真发出去）

### 3.1 `ChatInput.tsx`：留住 `File`，失败不清空

  `onKeyDown` 里改成 `void submit()`。**不要**为此加 `disabled`，也不要加"发送失败"之类的文字。

- 已选附件预览：`file.type.startsWith('image/')` → `<img src={previewUrl}>`；否则文件块里显示 `file.name`（原来显示的是扩展名）。

### 3.2 `useChatData.ts`：先上传、再发送

`send` 改成：

```ts
const send = useCallback(
  async (text: string, files: File[], nextMode: ChatMode = mode): Promise<boolean>
)
```

逻辑（**顺序不许变**）：

```
body = text.trim()
若 body === '' 且 files.length === 0 → return false
setSending(true)
try {
  ids = []
  for (const file of files.slice(0, 4)) {
    const base64 = await readFileAsBase64(file)
    const added = await window.api.attachment.add({ name: file.name, mime: file.type, base64 })
    若 !added.ok → console.error('[chat] attachment.add 失败', added.error) → setSending(false) → return false
    ids.push(added.data.id)
  }
  const sent = await window.api.msg.send({
    text: body,
    mode: nextMode,
    ...(ids.length > 0 ? { attachmentIds: ids } : {})
  })
  若 !sent.ok → console.error('[chat] msg.send 失败', sent.error) → setSending(false) → return false
  return true
} catch (e) {
  console.error('[chat] 发送失败', e)
  setSending(false)
  return false
}
```

两条硬约束：

- **成功分支不许 `setSending(false)`**：转圈由主进程 `ai.status`（`thinking` → `idle`）收口，本地提前复位会让转圈闪一下。
- **渲染层不做 mime 白名单、不做体积校验**：25 MiB 上限与五个 mime 全在主进程（`attachmentService`），重复校验只会把可读文案换成通用句。

`ChatPanel.tsx` 的接线跟着改：`onSend={(text, files) => data.send(text, files, data.mode)}`。

### 5.5 `chatViewModel.ts`：`formatClock`

```ts
/** 消息时间 → 本地 HH:mm。非法/空串 → ''（调用方据此决定这一格进不进 DOM） */
```

规则：`new Date(iso)` 为 `NaN` → `''`；否则 `pad(getHours()) + ':' + pad(getMinutes())`。**不许**用 `toISOString().slice(11,16)`（那是 UTC，会和用户眼里的时间差 8 小时）。

## 10. 验收（6 条，别做分子料理）

1. **任务模式**：粘一张截图 + 打一句话 → 发送 → 气泡里出现「蓝色图标 + 文件名」胶囊，没有铺开的大图 → 鼠标**悬停胶囊**，上方浮出缩略图 → 移开消失 → AI 回复能说出图里的内容。
2. **纯图**：不打字，只粘一张图 → 发送按钮可点 → 发出去只有胶囊 → AI 仍有回复。
3. **聊天模式**：切到聊天模式，发一张图 + 一句话 → 图照常收成胶囊、照常入库，AI 回复**不提图里的内容**（这是契约：聊天模型不识字图，不许当 bug 修）。
4. **操作行**：自己发一条消息 → 气泡右下常驻「时间 复制 撤回 编辑」→ 点复制 → 图标变对勾，粘到记事本有原文 → 时间与系统时间一致。
5. **撤回 / 编辑**：点「撤回」→ 这条和下面 AI 回复一起消失，输入框**空**；点「编辑」→ 同样消失且原文回到输入框（带图的消息撤回后，输入框里**没有残留附件**）。
6. **失败保留**：传一个 >25 MiB 的图（或把模型名改坏后发图）→ 发送失败时**输入框文字和缩略图都还在**，没有被清空。
