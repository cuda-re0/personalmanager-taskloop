## 2. A 的规格（写死，别自己扩）

`[+]` 的可见性由**任务状态**决定，不由 verdict、不由 `isLatest`：

| 任务状态 | `[+]` 与隐藏 input |
|---|---|
| `todo` / `doing` / `reviewing` | **渲染** |
| `done` / `missed` / `discarded` / `archived` | **不渲染**（整个按钮与 input 都不进 DOM） |

- 判据只有一个：`task.status`。不要用 `isLatest`、不要用 `verdict.verdict`、不要加「任务已结束」这类提示文字。
- `partial` / `fail` 之后任务回到 `doing` → `[+]` **必须还在**：右栏 ① 没有证据 UI，这是用户「补材料再提交」的唯一入口。删掉它等于砍掉一条正常路径。
- `EvidencePanel` 加一个布尔 prop（名字自定，如 `canAdd`），由 `TaskReviewCard` 传 `task.status` 算出来的值；`busy` 的语义不变（有动作在飞时禁用）。
- 不新增任何文案、不新增样式、不改 `[+]` 的外观与位置。
