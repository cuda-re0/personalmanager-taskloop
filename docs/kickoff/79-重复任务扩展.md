## B 规格

### B1 规则字符串：**只允许一种语法**

```
EVERY:<n>:<unit>[:<selector>]
```

| unit | selector | 含义 | 例子 |
|---|---|---|---|
| `D` | 无 | 每 n 天 | `EVERY:3:D` = 每 3 天一次 |
| `W` | 周几列表，**必填** | 每 n 周的指定周几 | `EVERY:2:W:1,3` = 每 2 周的周一、周三 |
| `M` | 号列表，可空 | 每 n 月的指定号；空则用锚点当天的号 | `EVERY:1:M:15` / `EVERY:2:M:1,15` |
| `Y` | `MM-DD`，可空 | 每 n 年的指定月日；空则用锚点的月日 | `EVERY:1:Y:11-06` |

**兼容读入（只读，不再写出）**：

- `null`、`''`、`'DAILY'` → 视为 `EVERY:1:D`
- `'WEEKLY:1,3,5'` → 视为 `EVERY:1:W:1,3,5`

**写出一律用新语法**，不许再写 `DAILY` / `WEEKLY:`。

其他硬性约定：

- 读入大小写不敏感（`unit` 与 `selector` 里的 `MM-DD`）；**写出一律大写**
- 列表**升序去重**，逗号后无空格
- `n` 必须是正整数，范围：`D` 1..365、`W` 1..52、`M` 1..24、`Y` 1..10

### B2 `repeatRule.ts` 导出（签名固定）

```ts
export type RepeatUnit = 'D' | 'W' | 'M' | 'Y'

export interface RepeatRule {
  n: number
  unit: RepeatUnit
  weekdays: number[]   // W 用，1..7 ISO；其余 []
  monthDays: number[]  // M 用，1..31；空数组表示「用锚点当天的号」
  monthDay: string | null // Y 用，'MM-DD'；null 表示「用锚点的月日」
}

export function parseRepeatRule(rule: string | null): RepeatRule
export function serializeRepeatRule(r: RepeatRule): string
export function matchesRepeatDay(rule: string | null, day: string, anchor: string): boolean
export function describeRepeatRule(rule: string | null): string
```

- **`serializeRepeatRule` 永不返回 `null`**：每天就是 `EVERY:1:D`
- 本文件**零运行时依赖**：不许 import electron、react、`@renderer/*`、db 层。可以 import `@shared/localDay`
- `parseRepeatRule` 非法输入**抛错**，消息中文一句话，不带堆栈
- **`matchesRepeatDay` 的第三个参数 `anchor` 必填**，是「这一系列重复的起算日」（`YYYY-MM-DD`）。间隔式重复靠它算偏移，没有它「每 3 天」无从判定

### B3 非法输入（逐条抛错，消息中文一句话）

- `n` 为 0、负数、非整数、超出 B1 范围
- `unit` 不是 `D` / `W` / `M` / `Y`
- `W` 没有 selector、或 selector 为空、或含 1..7 之外的值
- `M` 的号含 1..31 之外的值
- `Y` 的 `MM-DD` 不是闰年里的合法日期（`02-30`、`04-31`、`13-01` 非法）
- 段数不对（`EVERY:3`、`EVERY:3:D:1`、`FOO:1:D`）

### B4 判定算法（写死，不许自己发挥）

先把 `day` 与 `anchor` 都当本地日字符串，算出 `diff = daysBetween(anchor, day)`。

- **`D`**：`diff >= 0 && diff % n === 0`
- **`W`**：`isoWeekday(day)` 必须在 `weekdays` 里；再把 `anchor` 与 `day` 各自回退到所在周的周一，算周差 `weeks`，要求 `weeks >= 0 && weeks % n === 0`
- **`M`**：月差 `months`（按 `年*12+月` 算）满足 `months >= 0 && months % n === 0`；再看号是否命中：
  - `monthDays` 非空：命中条件为「当日号 ∈ monthDays」**或**「当日是当月最后一天，且 monthDays 里存在大于当月天数的值」（短月补齐到月末）
  - `monthDays` 为空：当日号 === `anchor` 的号，同样适用短月补齐（锚是 31 号、当月 30 天 → 当月最后一天命中）
- **`Y`**：年差 `years >= 0 && years % n === 0`；再看月日：
  - `monthDay` 非空：`MM-DD` 严格相等；特例 `02-29` 在平年由 `02-28` 命中
  - `monthDay` 为空：用 `anchor` 的月日，同样适用 `02-29` 特例

**`diff` / `weeks` / `months` / `years` 小于 0 一律 false**（锚点之前的日期不算），不做「向前推」的补算。

### B5 `describeRepeatRule` 的中文串（逐字写死，不许润色）

`n === 1` 时省略「每 N」，其余一律带：

| 规则 | 输出 |
|---|---|
| `EVERY:1:D` | `每天` |
| `EVERY:3:D` | `每 3 天` |
| `EVERY:1:W:1,3,5` | `每周一、三、五` |
| `EVERY:2:W:1,3` | `每 2 周的周一、三` |
| `EVERY:1:M:15` | `每月 15 日` |
| `EVERY:2:M:1,15` | `每 2 月的 1、15 日` |
| `EVERY:1:M:`（selector 空） | `每月同日` |
| `EVERY:1:Y:11-06` | `每年 11 月 6 日` |
| `EVERY:2:Y:11-06` | `每 2 年的 11 月 6 日` |

周几单字数组按 ISO 1..7：`一 二 三 四 五 六 日`。数字前后各一个半角空格。
