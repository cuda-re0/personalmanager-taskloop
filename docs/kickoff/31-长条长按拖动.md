# 31 · 长条「点按展开 / 长按拖动」（v0.32）

基线 `aed30d1`（v0.31 已审核 PASS，用户手点通过）。单独跑，别与任何会话并行。

## 1. 现象（用户验收 v0.31 时提的，代码事实已确认）

用户原话：「我试了一下，还行，然后缩小了也要能拖动」。

**长条态现在一个像素都拖不动**，根因在代码里能直接看到：

- `.hud-ball` 写了 `-webkit-app-region: drag`，
- 但 `.hud-hit` 用 `position: absolute; inset: 0` 盖满整条，并写了 `-webkit-app-region: no-drag`，
- Electron 的 drag 区**收不到任何鼠标事件**，`no-drag` 又把这层覆盖区域的拖动剥掉 → 整条只剩点击。

修法不是把热区缩小（那会变成"某块能拖某块不能拖"），而是按用户裁决：

> **点按点击，长按拖动。**

即整条都不再依赖原生拖动，改由渲染层自己判手势。契约见 04 §5.2.2。

## 2. 手势规格（04 §5.2.2，逐条照做）

| 手势 | 判定 | 结果 |
|---|---|---|
| 点按 | 按下后 `< 260ms` 松开，位移 `≤ 4px` | `setMode('panel')` |
| 长按 | 按住 `≥ 260ms` | 进入拖动；之后指针怎么移，窗口跟到哪 |
| 抖动 | 未到 260ms 但位移已 `> 4px` | 什么都不做（既不展开也不拖） |

常量放 `src/renderer/hud/hudModel.ts`，导出：

```ts
export const LONG_PRESS_MS = 260
export const TAP_TOLERANCE = 4
```

实现约束：

1. `.hud-ball` **删掉** `-webkit-app-region: drag`（整条改为 no-drag，默认值即可，不用显式写）。
2. `.hud-hit` 保留（承接 pointer 事件 + `aria-label`），但**删掉 `onClick`**——点击只由 `pointerup` 判定，
   留着 `onClick` 会让长按松手时多触发一次展开。
3. Pointer Events：
   - `onPointerDown`：只接主键（`e.button !== 0` 直接 return）；`e.currentTarget.setPointerCapture(e.pointerId)`；
     记 `startScreen = { x: e.screenX, y: e.screenY }`；起 260ms 定时器，到点置 `dragging = true`。
   - `onPointerMove`：未进入拖动时，若 `|dx| + |dy| > TAP_TOLERANCE` → 清定时器、标记 `cancelled`（抖动，不点不拖）；
     已进入拖动时，把 `screenX/Y` 差值累加进待发 delta，`requestAnimationFrame` 里发一次
     `api.hud.dragBy({ dx, dy, end: false })`，一帧最多一次。
   - `onPointerUp`：清定时器；若 `dragging` → 把剩余 delta 发一次 `dragBy({ dx, dy, end: true })`；
     否则若未 `cancelled` 且位移 `≤ 4px` → `setMode('panel')`。
   - `onPointerCancel` 与 `onLostPointerCapture`：与 `pointerup` 同一套收尾（拖动中则 `end: true`），
     不许留 `dragging` 卡住的路径。
4. 位移一律用 `e.screenX/screenY` 的差值——窗口自己在移动，`clientX` 会漂。
5. 拖动中**不判形态**（长条拖到屏幕中间也不当场变面板），松手才判。拖动中途窗口变大 = 指针相对位置突变 = 手感跳。
6. `cursor: grab` 常态；拖动中加 `.is-dragging` → `cursor: grabbing`。这是唯一新增的视觉反馈，无文字。
7. 面板态不动：仍是 `.hud-head` 的原生 `drag`。但 `.hud-grow` 补一行 `min-width: 24px`，
   保证面板拉到最窄 280 时头部仍有可抓的空白（tab 全占满就抓不动了）。

## 3. 主进程 `hud.dragBy`（新通道）

签名：`dragBy(input: { dx: number; dy: number; end: boolean }): void`

```ts
export function dragBy(dx: number, dy: number, end: boolean): void {
  const current = requireState()
  if (current.mode !== 'ball') return                 // 面板走原生拖动，这条路只服务长条
  if (!Number.isFinite(dx) || !Number.isFinite(dy)) return

  const rect = requirePort().getBounds()
  const area = requireDisplays().nearestWorkArea(rect)
  anchor = clampBallPoint(area.workArea, { x: rect.x + Math.round(dx), y: rect.y + Math.round(dy) })
  current.displayId = area.displayId

  if (!end) {
    applyBounds()   // 内部设 expectedRect，move 回声会被过滤，不会触发 judgeShape
    return
  }

  persistPosition(anchor)
  persistDisplayId(area.displayId)

  // 松手才判形态（拖动中不判）
  const step = resolveDragStep('ball', area.workArea, {
    x: anchor.x, y: anchor.y, width: BALL_W, height: BALL_H
  })
  if (step === 'expand') {
    const panel = peekPanelBounds(area.workArea, anchor, panelSize)
    enterMode('panel', area, { x: panel.x, y: panel.y })
    return
  }
  applyBounds()
}
```

- 必须复用现有 `applyBounds()`（它负责设 `expectedRect` 做回声抑制）。**不许自己 `setContentBounds`**。
- 长条态 clamp 由 `clampBallPoint` 保证：整条不出屏（这是 v0.31 的既定口径，不改）。
- 拖动中不落库（`end:false` 只移窗），松手才写 `hud.position`。
- 通道从 41 → **42**。`hudChannels.test.ts` 的条数按实际断言改数字。

## 5. 测试（锁关键行为，不逐像素）

`hudService.test.ts`：

1. `dragBy(20, 30, false)` 后窗口 x/y 各平移 20/30，且 `hud.position` **没有**被写；
2. 把长条往右下拖到超出工作区 → 位置被 `clampBallPoint` 夹在屏内（整条不出屏）；
3. `dragBy(0, 0, true)` 在贴右位置 → 位置落库，形态仍是 `ball`；
4. 长条先被拖到离左右边 > 48 再 `end: true` → 形态变 `panel`（走 `enterMode`，不是自己 setBounds）；
5. `panel` 态调 `dragBy` → 直接返回，bounds 与 position 都不变。

`hudWiring.test.ts`：

- `HudBall.tsx` 含 `onPointerDown` / `onPointerMove` / `onPointerUp` / `setPointerCapture`；
- `HudBall.tsx` 里**没有** `onClick=`（点击只走 pointerup）；
- `hud.css` 里 `.hud-ball` 规则块内没有 `-webkit-app-region: drag`；
- `hudModel.ts` 导出 `LONG_PRESS_MS = 260` 与 `TAP_TOLERANCE = 4`。

## 6. 验收（三条主路径）

1. **点按**：点一下长条 → 开面板；面板里按 ESC → 回长条。
2. **长按拖动**：按住长条约半秒再拖 → 窗口跟着走，松手停在原地且不出屏；
   按住不到半秒就松手 → 开面板；按住立刻快速划一下（没到半秒）→ 什么都不发生。
3. **面板最窄也能拖**：面板拉到 280×320，抓头部空白处能拖动整个窗口。
