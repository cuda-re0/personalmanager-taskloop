# 26 · W6B：右栏比例分割线（v0.29）

> 基线：`d16eaff`（v0.28 已审核 PASS）。本单**单独跑，不能与任何会话并行**——动 `index.tsx` 与右栏全部样式。

## 0. 背景与用户裁决

v0.28 用「③④ 定高 348、① 吸差」解决了「详情展开压缩积分区」，但用户验收后裁决这个模型不对：

> 「要求中间的分割线能拖动，且静止时，上下比例不会因为窗口变化而变化，不能一个变，一个不变。」

两个确认过的决定：
1. **分割线位置：日历上方**（① | 分割线 | ②③④ 整块）。
2. **比例要记住**：重启后保持拖过的比例。

契约已落 `04 §4①` v0.29 段，本词与其一字不差冲突时以 04 为准并停下来报告。

## 1. 目标模型（04 §4① v0.29）

```
┌──────────────┐
│ ① 任务区      │  flex-grow = 1-r，min-height:0，内部滚
├──────────────┤  ← 分割线（可拖，无文字）
│ ② 日历 240px │  下半块内固定
│ ③④ 积分区    │  flex:1，min-height:0，内部滚
└──────────────┘  下半块整体 flex-grow = r
```

- 上下两半都 `flex-basis: 0` + 按比例 `flex-grow`——窗口高度变化时**两侧等比伸缩**。
- `r` = 下半份额（小数）。默认 `0.71`（等价 v0.28 默认窗观感 588/829）。
- 持久化：**渲染层 localStorage**，键 `taskloop.rightSplit`，存 r 的十进制字符串。
  **不走 settings 表**——`AppSettings` 是封闭接口（02 §3.0，15 个 key 锁测试），
  为一条 UI 偏好动它要牵 `src/shared`+`src/main`+01/02 三个契约，不值。读入时
  非法/越界值回落 0.71。
- 拖动夹限：上半 ≥ 160px、下半 ≥ 360px；到限夹住不回弹。夹限换算按**当前容器实际高度**算。
- 分割线：水平条，命中区建议 6~8px、`cursor: row-resize`、`role="separator"` +
  `aria-orientation="horizontal"`。**无任何文字**（04 §7）。
- 拖动用 Pointer Events + `setPointerCapture`，move 期间实时更新（无过渡动画），
  pointerup 时写一次 localStorage。
- 详情展开/收起不许移动分割线（全部由 ① 内部滚动吸收）；②③④ 高度变化只来自
  拖动或窗口缩放。

## 3. 实现要点

1. **纯逻辑与组件分离**：`splitModel.ts` 导出
   - `DEFAULT_SPLIT = 0.71`、`MIN_TOP_PX = 160`、`MIN_BOTTOM_PX = 360`
   - `ratioFromY(y: number, rect: {top; height}, bottomPx: number): number`——把指针 y 换算成下半像素 → 夹限 → 除以容器高得 r
   - `parseSplit(raw: string | null): number`——非法/越界回落 0.71
2. **flex 写法**：两半都用 `flexGrow` 行内样式（`1-r` 与 `r`）+ `flexBasis: 0` +
   `minHeight: 0`；不要用百分比 `flex-basis`（分割线自身高度会搅乱比例）。
3. **拖动中不要每帧写 localStorage**——只在 pointerup 写一次。
4. **StrictMode**：拖动事件不走 effect，不受双跑影响；如用 effect 同步初始 r，注意去重。
5. 删旧断言时**别动** v0.28 的其他成果：日历层就地替换、toggleDay、零请求原则原样保留。

## 5. 真机验收（隔离库 + 临时端口，先核对身份——07 硬约束 3）

1. 默认观感 ≈ v0.28（上 241 / 下 588 上下 3% 内）。
2. 拖分割线 → 两侧实时跟随；拖到顶/底极限 → 夹住不回弹、不溢出。
3. 拖到 50:50 → 拉伸窗口高度 → **比例保持**（两侧像素等比变化，误差 ≤ 2px）。
4. 重启应用 → 比例保持 50:50。
5. 详情展开/收起 → 分割线位置一像素不动，① 内部出滚动条。
6. 日历层：点日期 → ③④ 替换、随下半块伸缩；打卡刷新；再点同天关闭。
7. 全程无横向滚动、无新增可见文字。
