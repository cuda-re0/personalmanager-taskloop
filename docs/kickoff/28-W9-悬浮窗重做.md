## 1. 规格（唯一来源：`04 §5` v0.30，逐条照做）

```ts
HudMode = 'ball' | 'panel'

BALL_SIZE   = 56
PANEL_W     = 360      // 默认
PANEL_H     = 480
PANEL_MIN_W = 280      PANEL_MIN_H = 320
PANEL_MAX_W = 720      PANEL_MAX_H = 900
TOP_RATIO   = 0.1      // 首次启动：球顶距工作区顶 = 高度 × 0.1
```

- `ball`：`x = workArea.x + workArea.width − 56`（贴右，永远），`y` 可拖、clamp 进工作区。
  拖动中 `move` 事件里**强制把 x 拉回右边缘**（用户只能上下移动它）。
- `panel`：位置自由（clamp 进工作区）、尺寸取 `hud.size`（null → 360×480）。
- 落库：位置 → `hud.position`（ball 只写 y，x 写 null）；尺寸 → `hud.size`；
  形态 → `hud.mode`。三处都在拖动/拉伸**收尾**时写（去抖 300ms），拖动中不写。
- 旧值兼容：`hud.mode` 读到 `'dock-bar'` / `'float-pod'` / 任何未知串 → 一律按 `'ball'` 起。
- 已知显示器不在（拔屏）→ 回落主屏，重新 clamp，不留在屏幕外。

## 2. 两页（`04 §5.3`）

- 头部一行：`● N/M`、`今日 +N`、两个 tab `今天` `设置`。头部整体是拖动把手（`drag`）。
- **今天页**：今日行（每日 occurrence + 今天到期的限时/活动），每行 = 完成控件 + 标题；
  每日 → `occurrence.complete`，限时/活动 → `task.complete`；失败行内显示 `AppError.message`
  原文 4s（与主窗同口径）。底部保留一句话加任务输入（`task.createManual`）。
- **设置页**：`背景颜色`（`<input type="color">`）、`透明度`（range 0.3–1 step 0.05）、
  `关闭悬浮窗`（`hud.setVisible({visible:false})`）。前两项即时落库并即时生效。
- **文字白名单就是上面这些**（`今天` `设置` `背景颜色` `透明度` `关闭悬浮窗` `● N/M` `今日 +N`
  + 任务标题 + 错误原文）。不写空态文字、不加 tooltip、不加说明、不加第四个设置项。

## 3. 背景透明度

渲染层把 `hud.background`（null → 主题 `--bg`）与 `hud.opacity` 合成 `rgba()` 写进
CSS 变量 `--hud-bg`，`.hud-ball` / `.hud-panel` 的 `background` 用它。
**禁止**把 `opacity` 加在容器上（文字会一起变淡）。

## 4. settings / 通道变更

新增 `hud.size: { width, height } | null`（默认 null）、`hud.background: string | null`（默认 null）、
`hud.opacity: number`（默认 1，guard 里 clamp 到 0.3–1）。
删除 `hud.expanded` 与 `hud.setExpanded` 全链路（`channels.ts` / `types/ipc.ts` / `guards.ts` /
`registry.ts` / `preload`）。`hud.getState` 返回 `{ mode, displayId, visible }`。
通道条数同步改（现在有 36 条，删 1 条后 **35**；以 `tests/ipc/hudChannels.test.ts` 的实际断言为准，
改数字时只改数字）。

## 7. 手点验收（6 条，逐条写实测）

1. 清掉 `hud.position` / `hud.size` 重启：球 56×56、贴右边缘、球顶距工作区顶 ≈10%（误差 ≤8px）。
