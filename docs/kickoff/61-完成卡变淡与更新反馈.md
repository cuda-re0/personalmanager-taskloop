## §0 三件事与用户原话

**用户反馈（2026-11-03）：**

1. 「已经完成的任务卡也要变灰」——已确认指**会话区里判定完成的那张审核卡**（`TaskReviewCard`，`verdict === 'pass'` 那一条）。
2. 「点击检查更新的反馈太弱了」——现在的表现：点完只闪一句「已是最新」，2.6 秒消失；按钮在检查期间只是变灰，没有任何"正在查"的视觉。
3. 「每次有更新就升版本号啊，不然你那版本号放那有啥用」——版本号是自动更新的唯一判据，不升就永远检测不到新版本。

**用户对第 2 条的裁决：**

> 检查完后，让按钮文字变成已是最新，停留 2s。2 也做。

即：结果写进**按钮文字本身**，停留 2 秒；同时按钮在检查期间要显示「检查中…」。

**已核实的事实（不要重新调研）：**

- `.review-card--pass` 目前只设了左边框颜色，**没有任何淡化**；任务列表的 done 行是 `opacity: 0.5`（`tasks.css` `.task-row--done`）。
- 设置页版本行的结构：`版本 / v0.60.0 / [检查更新] / (note span)`。
- `refreshUpdate()` 成功后调 `flashUpdateNote('正在更新' | '已是最新')`，写进 `settings-notice` 那个 span，`UPDATE_NOTE_MS = 2600` 后清空。
- `checking` 只用于按钮 `disabled`，按钮文字恒为「检查更新」。
- 主进程 `app.checkUpdate` 返回 `applying: true` 时，会在 **2000ms 后**调用 `applyUpdate()` 覆盖并重启——所以按钮显示「正在更新」的这 2 秒正好是真实等待时间。
- 绿色版 `resources/app/package.json` 与 `updates/latest.json` **都是 0.60.0**，`compareVersion` 返回 0，所以永远「已是最新」。这不是 bug，是版本号没升。

## §2 检查更新：结果写进按钮

### §2.1 状态加一个字段

`src/renderer/main/features/settings/useSettingsData.ts`：

- `SettingsUpdate` 接口加 `buttonNote: string | null`，注释写：`按钮上的结果文字（'已是最新' / '正在更新'），2 秒后回 null；错误不走这里`。
- `EMPTY_UPDATE` 里加 `buttonNote: null`。
- 新增常量 `UPDATE_BUTTON_MS = 2000`（放 `UPDATE_NOTE_MS` 旁边）。
- 新增 ref `buttonNoteTimer`（照 `updateNoteTimer` 的写法），并在卸载清理的 `useEffect` 里一并 `clearTimeout`。

### §2.2 `refreshUpdate` 改写

```
开始：
  setUpdate(prev => ({ ...prev, checking: true, buttonNote: null }))

成功（res.ok）：
  setUpdate(prev => ({
    ...prev,
    version: res.data.current,
    latest: res.data.latest,
    hasUpdate: res.data.hasUpdate,
    checking: false,
    buttonNote: res.data.hasUpdate ? '正在更新' : '已是最新'
  }))
  起 2000ms 定时器：把 buttonNote 置回 null（只清这一个字段，不动其它）
  —— 原来那句 flashUpdateNote(...) 删除

失败（!res.ok 或 reject）：
  setUpdate(prev => ({ ...prev, checking: false }))
  仍然调 flashUpdateNote(错误 message)   ← 一字不改
```

**为什么要删成功路径的 `flashUpdateNote`**：结果已经写在按钮上，再在右边冒一句是同一句话说两遍。

**清定时器的细节**：每次点击先 `clearTimeout(buttonNoteTimer.current)`，避免连点后前一次的定时器提前把新结果抹掉。

### §2.3 按钮文字

`src/renderer/main/features/settings/SettingsDrawer.tsx`，按钮内容改成三态：

```
checking 为真        → '检查中…'
checking 假、buttonNote 非 null → buttonNote
其余                 → '检查更新'
```

要求：

- **只改按钮里的文字表达式**，`disabled`、`className`、`onClick`、`type` 一个都不许动。
- 省略号必须是**单个中文省略号字符 `…`（U+2026）**，不是 `...`。
- `settings-notice` 那个 span 保持原样（错误靠它显示）。

### §2.4 白名单文案

`tests/renderer/settingsWiring.test.ts` 的 `ALLOWED` 集合里追加一项 `'检查中…'`（同样是 U+2026）。

**这条不加就是一条硬红**：该测试扫描设置目录下所有中文字面量，不在白名单里的全部报错。
